# 安全、HTTP 与嵌入式 Web

任何监听端口、接受不可信输入、返回本地数据或嵌入网页资产的变更都按高风险处理。高风险意味着先建威胁模型并扩大验证，不意味着禁止合理修改。

## 客户端不保存真正秘密

`BuildConfig`、资源文件、Manifest meta-data、assets 和客户端源码都会进入 APK，可被读取或逆向。它们只能承载非秘密的编译配置，不能作为 secret 存储。

不得硬编码、提交或暴露：

- API secret、长期 token、密码、私钥和签名材料；
- 用户隐私数据、Cookie、认证 header、书源私密参数；
- 带敏感查询参数的 URL、完整请求/响应体；
- 真实秘密的截图、测试夹具、文档示例和错误输出。

按威胁模型选择后端保管、短期凭据或受保护的运行时存储；同时检查最小权限、过期、撤销、轮换和日志脱敏。若仓库中已存在疑似真实秘密，只报告位置和修复方向，不在对话或新文件中复述值。

## HttpServer 与 WebSocket 是高风险边界

以下内容均需安全审查：HttpServer、WebSocket、controller、route、上传、下载、备份、CORS、鉴权、token 管理和监听地址。

变更前先列出：

1. 暴露的端点/事件、方法、输入、输出和本地数据权限。
2. 默认监听地址、端口、是否可能被局域网或外部网络访问。
3. 每条路由的公开/私有分类和服务端鉴权位置。
4. token 的生成、传输、存储、比较、过期、撤销与日志路径。
5. 上传/下载、备份恢复和文件系统可达范围。

## 审查清单

- 默认配置是否最小暴露；关闭鉴权是否需要显式、可见且受限的操作。
- 每条私有路由是否在服务端强制鉴权，而不是只靠前端隐藏按钮。
- missing、wrong、expired、revoked、correct token 以及 auth disabled 是否有明确行为和测试。
- token 是否避免出现在 URL、访问日志、异常、分析事件或返回体；比较方式和传输通道是否符合威胁模型。
- CORS 是否只允许必要 origin、method、header 和 credential 组合，避免宽泛通配。
- 请求体、消息、文件数量和文件大小是否有限制，超限是否尽早拒绝。
- JSON/对象反序列化是否限制类型、深度和缺失/额外字段，畸形输入是否安全失败。
- 路径与文件名是否规范化并约束在允许根目录，拒绝 `..`、绝对路径、链接逃逸和覆盖敏感文件。
- 错误是否脱敏且不返回堆栈、绝对路径、内部 SQL、token 或隐私数据。
- 日志是否只保留必要元数据，并在认证、备份、上传、WebSocket 生命周期中一致脱敏。

至少补充未认证、越权、畸形输入和超大输入测试；按端点再补路径穿越、重复请求、并发、断连、重放或 CORS 负例。安全测试必须断言拒绝状态和无副作用，而非只看响应文案。

## `modules/web` 构建与同步

`modules/web` 是独立 Vue/pnpm 工程，不属于 Gradle 模块。以 `package.json` 和脚本现状为准：

- `pnpm build` 组合 TypeScript/Vue 类型检查与 Vite 生产构建，并生成 `modules/web/dist/`；
- 随后的 `scripts/sync.js` 只有在存在 `GITHUB_ENV` 环境变量时才复制到 `app/src/main/assets/web/vue/`；
- 普通本地环境会打印取消复制，因此本地 `pnpm build` **不代表** Android assets 已同步。

需要发布内嵌网页时：

1. 在受支持的 Node/pnpm 环境安装依赖并运行类型检查与生产构建。
2. 明确选择、记录并执行仓库/CI 认可的同步方式；不要仅为触发脚本而伪装 CI 环境，除非已核验副作用。
3. 对比 `dist/` 与 `app/src/main/assets/web/vue/`，检查新增、删除、哈希文件、source map 和陈旧文件。
4. 再构建受影响 Android variant，并验证真实内嵌页面及服务端接口。

只改 Web 源码但不需要更新内嵌产物时，应明确说明 assets 未同步及发布影响。

## 专项技能路由

- Vue/页面交互：发现并加载当前环境的 Vue、前端和可访问性专项技能。
- API、HttpServer、WebSocket：加载 API 设计/实现与安全审查专项技能。
- 上传、备份、路径和秘密：加载安全审查技能，并把负例测试列入验收。

若专项技能不可用，记录这一限制并执行本页检查；不得声称已完成未运行的专项流程。
